# Анастасия Оточина — технический писатель. Портфолио

Перехожу в техническое письмо из поддержки корпоративных систем. 15 лет работала с POS-терминалами, онлайн-кассами, страховым ПО — и на каждом месте документировала: базы знаний, пользовательские инструкции, баг-репорты, API.

Здесь пять документов разных типов — от API-документации до release notes.

## Документы

### API-документация

- [`osago-api.md`](osago-api.md) — документация REST API ОСАГО: аутентификация, расчёт котировки, создание договора. Примеры запросов и ответов, коды ошибок. **Аудитория:** разработчики, аналитики, QA-инженеры.

### Баг-репорты

- [`bug_report_kassa.md`](bug_report_kassa.md) — баг-репорт по реальному инциденту: расхождение суммы при закрытии дня в кассовом модуле. Шаги воспроизведения, диагностика, корневая причина, хронология. **Аудитория:** команда разработки, вендор ПО.

### Пользовательские инструкции

- [`pos_terminal_setup.md`](pos_terminal_setup.md) — инструкция по подготовке POS-терминала к выезду на точку: установка ПО, удалённая загрузка, тестовые операции, чек-лист готовности. **Аудитория:** инженеры технической поддержки.
- [`online-kassa-troubleshooting.md`](evotor/online-kassa-troubleshooting.md) — гайд по типовым проблемам онлайн-касс Эвотор: нет связи с ОФД, ошибки ФН, ошибки эквайринга, проблемы печати. Таблица «причина → проверка → решение». **Аудитория:** инженеры поддержки.

### Release Notes

- [`evotorpos-8.18.5-release-notes.md`](evotor/evotorpos-8.18.5-release-notes.md) — release notes для кассиров: новые функции, исправления, риски, чек-лист проверки после обновления. **Аудитория:** кассир, конечный пользователь.
