## Что понадобится

Перед началом подготовки проверьте, что у вас есть:

- [ ] Терминал нужной модели (тип и модель — из задачи)
- [ ] Флэшка с актуальной версией ПО (версия зависит от модели терминала)
- [ ] Ноутбук с банковской утилитой загрузки
- [ ] Учётная запись инженера для банковской утилиты загрузки
- [ ] ID терминала для торговой точки (получен из задачи)
- [ ] Доступ к сети — терминал должен быть подключён к интернету для удалённой загрузки
- [ ] Тестовая карта (в идеале) или личная карта для тестовых операций

## Порядок действий

### 1. Взять терминал со склада

Возьмите терминал нужной модели. Визуальный осмотр необязателен — основная проверка работоспособности пройдёт на шаге 5 после удалённой загрузки. Если внешний вид вызывает сомнения, осмотрите корпус, экран, клавиатуру и отверстие картридера.

### 2. Установить актуальную версию ПО

Способ установки зависит от модели (Ingenico, Verifone, PAX — у каждой свои нюансы):

- с флэшки через USB-порт терминала;
- через компьютер с помощью утилиты загрузки.

Если на терминале уже установлена актуальная версия — шаг пропустите.

### 3. Настроить ID терминала в банковской утилите загрузки

ID настраивается не на самом терминале, а в банковской утилите загрузки под учётной записью инженера. Откройте утилиту, авторизуйтесь, настройте ID терминала под конкретную торговую точку. Полученный номер понадобится на следующем шаге — его нужно ввести на терминале.

### 4. Провести удалённую загрузку

Подключите терминал к сети. Зайдите в меню терминала → «Удалённая загрузка» → введите настроенный номер ID. Для кассовых терминалов — через кассовый модуль от банка.

Загрузка занимает около 5 минут, но время может отличаться в зависимости от модели и объёма загружаемых данных. Дождитесь успешного завершения — терминал перезагрузится с новыми настройками.

### 5. Тестовые операции

После загрузки проведите три операции подряд:

1. **Оплата** — проведите платёж (обычно 1 ₽). Используйте тестовую карту. Если тестовой нет — подойдёт личная карта. Способ зависит от типа: через меню для стационарных терминалов, через кассовый модуль — для кассовых.
2. **Отмена операции** — отмените тот же платёж.
3. **Снятие отчёта (закрытие дня)** — снимите отчёт.

Всё вместе проверяет бесконтактный ридер, чип и принтер (если терминал не кассовый). Если хотя бы одна операция не прошла — см. раздел [«Типичные проблемы»](#типичные-проблемы).

### 6. Готово

Если все тестовые операции прошли успешно — терминал готов к установке на торговой точке.

## Типичные проблемы

| Проблема | Что делать |
|----------|-----------|
| Удалённая загрузка зависла более 10 минут | Перезагрузите терминал и запустите загрузку заново. Если зависает снова — проверьте подключение к сети. |
| Тестовый платёж не прошёл, но ридер реагирует | Проверьте сумму платежа, баланс карты и статус счёта карты. Попробуйте другую карту. |
| Принтер печатает пустые строки | Перезагрузите терминал и повторите печать отчёта. Если не помогло — проблема в принтере, берите другой терминал. |
| Удалённая загрузка завершилась с ошибкой | Проверьте корректность введённого ID. Сверьте с номером, настроенным в банковской утилите загрузки. |
| Ни одна операция не прошла | Верните терминал на склад, возьмите другой той же модели, начните заново с шага 2. |

## Чек-лист готовности

Перед выездом на точку проверьте:

- [ ] Версия ПО актуальна
- [ ] ID терминала настроен в банковской утилите загрузки
- [ ] Удалённая загрузка прошла успешно
- [ ] Тестовая оплата прошла
- [ ] Отмена операции прошла
- [ ] Отчёт напечатан

Если все пункты отмечены — можно выезжать на точку.
