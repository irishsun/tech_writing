## Что нового

### Продажа ветеринарных препаратов

Касса поддерживает продажу ветеринарных препаратов по рецепту. Раньше такой сценарий не был доступен — теперь кассир может оформить продажу, если у покупателя есть рецепт.

На что влияет: открывает новый тип продаж для зоомагазинов и ветаптек.

### Частичная продажа ветеринарных препаратов

У кассира появляется возможность отпускать ветеринарные препараты частично, например, часть упаковки, а не упаковку целиком.

На что влияет: кассиру больше не нужно пользоваться обходными путями отпуска — продавать как обычный развесной товар.

### Печать отчета об открытии смены

Кассиру добавлена возможность допечатать отчёт об открытии смены, если в момент открытия смены чековая лента закончилась, и отчет не был распечатан.

На что влияет: кассиру не нужно искать отчет в истории чеков и самостоятельно распечатывать копию отчета.

## Исправления

| Проблема | Что исправлено |
|----------|---------|
| Для товара «Безалкогольное пиво» при указании единицы измерения — «л», невозможно указать количество | Добавили возможность указывать количество |
| Для товара «Безалкогольное пиво» при указании единицы измерения — «ед», была возможность указать количество больше 1 | Убрали возможность указать количество больше 1 |
| Ошибка создания карточки товара для безалкогольного пива | Карточка товара создаётся корректно |
| При создании карточки товара для безалкогольного пива автоматически не включался признак «Подакцизный товар» | Признак «Подакцизный товар» включается автоматически |

## Риски

> При продаже рецептурного ветеринарного препарата кассиру потребуется ввести данные рецепта. Если кассир не обучен работе с рецептурными продажами — он не сможет оформить продажу.

> При частичной продаже ветеринарного препарата остаток упаковки нужно учитывать вручную. Если не следить за остатками — фактическое количество товара на полке не будет совпадать с данными кассы.

> После обновления кассир не сможет указать количество больше 1 для товара «Безалкогольное пиво» с единицей измерения «ед». Если клиент покупает несколько бутылок — каждую нужно пробивать отдельно.

## Действия после обновления

После установки обновления проверьте:

- [ ] Продажу рецептурного ветеринарного препарата — касса запрашивает данные рецепта.
- [ ] Продажу ветеринарного препарата частично — можно указать часть упаковки.
- [ ] Открытие смены после замены ленты — касса предлагает допечатать отчёт.
- [ ] Продажу товара «Безалкогольное пиво» с единицей «л» — количество указывается.
- [ ] Продажу товара «Безалкогольное пиво» с единицей «ед» — количество больше 1 заблокировано.
